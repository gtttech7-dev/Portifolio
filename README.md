# Gabriel Tech — Landing Page

Landing page estática em React + Vite, criada para a Gabriel Tech.

## Rodar localmente

```bash
npm install
npm run dev
```

Para produção:

```bash
npm run build
npm run preview
```

## Onde editar

### Configuração geral
`src/config/site.js`

Altere:
- nome
- WhatsApp
- Instagram
- e-mail
- preços
- textos principais

O WhatsApp deve estar no formato internacional, sem `+`, espaços ou símbolos.

### Serviços
`src/data/services.js`

Adicione, remova ou edite os serviços.

### Projetos
`src/data/projects.js`

Adicione, remova ou edite os projetos demonstrativos.

### Imagens
`public/images/projects/`

Troque os arquivos por imagens reais. Para usar JPG/PNG, altere o caminho correspondente em `src/data/projects.js`.

## Observação

Os projetos apresentados nesta versão são explicitamente conceitos/projetos demonstrativos. Não há depoimentos ou avaliações inventados.
