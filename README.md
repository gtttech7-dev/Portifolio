# Gomark / Gomark Tech

Landing page da Gomark, criada com React + Vite.

## Rodar localmente

```bash
npm install
npm run dev
```

## Gerar build

```bash
npm run build
npm run preview
```

## Onde editar

- `src/config/site.js` — WhatsApp, Instagram, e-mail, preços e textos principais.
- `src/data/services.js` — serviços.
- `src/data/projects.js` — projetos demonstrativos.
- `public/images/projects/` — imagens dos projetos.

### Importante

Os números e links de exemplo em `site.js` precisam ser substituídos antes de publicar.
Os projetos exibidos são conceitos demonstrativos, não depoimentos ou trabalhos reais.


## Portfólio: aplicação de controle financeiro

O cartão **Controle Financeiro Pessoal** aponta para `https://controle-gastos-kohl.vercel.app/`. A imagem `public/images/projects/controle-financeiro.svg` é apenas uma prévia ilustrativa do dashboard; para mostrar fielmente o sistema, substitua-a por uma captura de tela real, mantendo o mesmo nome ou atualizando o caminho em `src/data/projects.js`.
